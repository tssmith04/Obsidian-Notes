**Theorem 1.4**
Assume that $\mathcal{A}$ is \\-closed. Then the following statements hold:
1. $\mathcal{A}$ is $\cap$-closed
2. If in addition $\mathcal{A}$ is $\sigma$-$\cup$-closed then $\mathcal{A}$ is $\sigma$-$\cap$-closed
3. Any countable (respectively finite) union of sets in $\mathcal{A}$ can be expressed as a countable (respectively finite) disjoint union of sets in $\mathcal{A}$.

**Theorem 1.12 (relations between classes of sets)**
1. Every $\sigma$-field is also a $\lambda$-system and a field
2. Every field on a finite set $\Omega$ is a $\sigma$-field

**Remark 1.17**
1. $\mathcal{C}\subset\sigma(\mathcal{C})$
2. If $\mathcal{C}_{1}\subset\mathcal{C}_{2}$ then $\sigma(\mathcal{C}_{1})\subset\sigma(\mathcal{C}_{2})$
3. $\mathcal{A}$ is a $\sigma$-field iff $\sigma(\mathcal{A})=\mathcal{A}$
4. $\lambda(\mathcal{C})\subset\sigma(\mathcal{C})$
